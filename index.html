Single Dimensional Arrays

A visual, interactive lecture page for understanding what arrays are, how to write them in C, and why programmers use them.

Lecture idea: Think of an array as a row of labeled storage boxes. Each box stores one value of the same data type, and the index tells the program which box to use.
Core concept

One name, many values

Suppose an electrical engineering program needs five voltage samples:

3.3
3.1
3.4
3.2
3.5

All five values can be grouped under one array name, such as voltage.

Indexes

Counting starts at 0

In C, the first element is index 0. For an array of 5 elements, the valid indexes are 0 through 4.

3.3
3.1
3.4
3.2
3.5
[0]
[1]
[2]
[3]
[4]
↑ voltage[0] is the first element
Mental model

Array = same type + fixed number of elements + one name

Same typeEvery element is the declared type, such as int, float, or double.
Fixed sizeThe size in a normal C array determines how many elements can be stored.
Indexed accessUse square brackets: array[index].
Declaration

Write the array type and size

int samples[5];

This declares an integer array named samples with space for 5 integers.

Pattern: data_type array_name[size];
Initialization

Give the elements starting values

int samples[5] = {10, 20, 30, 40, 50};

The values are stored in indexes 0 through 4.

Reading & changing values

Read an element

int x = samples[2];

x becomes 30 because index 2 contains 30.

Change an element

samples[2] = 99;

Only the third element changes; the array name still refers to the entire group.

Watch the index move

Animation: accessing array elements

The loop below visits each element in order. Notice how i becomes the index.

Ready
i = 0    statement: printf("%d", samples[i]);
for (int i = 0; i < 5; i++) { printf("%d ", samples[i]); }

The loop condition prevents access beyond index 4. This is one reason indexes and array size must be understood carefully.

Without an array

Repeated variable names

float v0, v1, v2, v3, v4;

Managing many separate variables becomes awkward as the data set grows.

With an array

One collection, easy loops

float v[5]; for (int i=0; i<5; i++) { read_sensor(&v[i]); }

The same pattern can process 5, 50, or 500 samples by changing the size and loop bounds appropriately.

Why programmers prefer them

1. Organized data. Related values live together under one meaningful name.

2. Repetition becomes simple. Loops naturally work with indexed collections.

3. Scales to larger data sets. The same code structure can handle many measurements.

4. Efficient memory layout. Elements are stored as a contiguous sequence in a normal C array.

Electrical engineering example: arrays are useful for ADC samples, lookup tables, filter coefficients, sensor readings, test vectors, and waveform data.
